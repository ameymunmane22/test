# Usage Limits and Quotas
Version 2.1 | Effective: 2026-05-10

## Plan Restrictions
- **Free**: 100 API calls/day.
- **Starter**: 10,000 API calls/day.

## Storage Limits
Following the recent infrastructure upgrade, storage limits have been expanded.
- **Professional Plan**: Users on this plan are allocated 1TB storage.
- **Enterprise Plan**: Custom allocated storage, typically 10TB+.
