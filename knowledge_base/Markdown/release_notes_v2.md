# Release Notes - Version 2.0
Version 2.0 | Published: 2025-10-01

## Major Upgrades
Welcome to Nexora V2.0! We have completely rewritten the backend in Rust for superior performance.

## API Limits Updated
To accommodate heavier enterprise workloads, the global API rate limit is now 10,000 requests per hour.
