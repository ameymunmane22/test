# Migration and Upgrade Guide
Version 2.1 | Effective: 2026-02-10

## Upgrading from V1 to V2
1. Back up all workflow configurations.
2. Update your API endpoints from `/api/v1/` to `/api/v2/`.
3. Note that V1 webhooks will be deprecated by December 2026.
4. Verify your integration keys.
