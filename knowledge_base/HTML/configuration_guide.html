Product Configuration Guide


Version 2.1 | Effective: 2026-01-20


Environment Setup


To set up your on-premises agent, you require Docker and Kubernetes (v1.24+). Set the NEXORA_ENV variable to production.


Integrations


Nexora integrates with Salesforce, Jira, and Slack. Configure OAuth2 endpoints in the integrations tab of the admin console.
