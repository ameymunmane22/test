Troubleshooting Guide


Version 2.1 | Effective: 2026-04-01


Login Failures


If you receive a 'SAML Assertion Failed' error, ensure your Identity Provider (IdP) clock is synced with an NTP server.


API Errors


A 429 error indicates you have hit your rate limit. Check the X-RateLimit-Reset header to know when you can resume making calls.
