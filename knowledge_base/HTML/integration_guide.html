Webhooks


Webhooks allow you to receive real-time HTTP notifications. To verify a webhook payload, compute the HMAC-SHA256 hash of the payload using your Webhook Secret.


Data Synchronization


By default, the Salesforce integration syncs data every 15 minutes. You can trigger a manual sync using the 'Sync Now' button.
